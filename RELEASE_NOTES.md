# ⚡ CorePulse v1.0.0 - Official Initial Release / Resmi İlk Sürüm

---

### 🇹🇷 Türkçe Açıklama

**CorePulse v1.0.0 ile tanışın!**  
CorePulse; MSI Center, ASUS Armoury Crate veya NZXT CAM gibi sistem kaynaklarını tüketen şişkin (bloatware) ve üretici bağımlı yazılımlara karşı geliştirilmiş, ultra hafif, yüksek performanslı ve modern bir donanım izleme merkezidir.

#### ✨ Öne Çıkan Özellikler:
* **Evrensel Donanım Telemetrisi (Ring 0):** Intel, AMD, NVIDIA, ASUS, MSI, Gigabyte vb. donanım üreticisi fark etmeksizin tüm CPU, GPU, Anakart, RAM ve Depolama birimlerini otomatik olarak tanır.
* **Gerçek Zamanlı Metrikler:** CPU/GPU çekirdek saat hızları, voltajları, hotspot ve bellek sıcaklıkları, anlık güç tüketimleri (Watt), fan devirleri (RPM), AIO pompa hızları ve SSD/NVMe sağlık durumları.
* **Düşük Seviye Hassas Takip:** Win32 API'leri ile anlık CPU yükü, RAM doluluğu ve ağ arayüzü (Ethernet/Wi-Fi) anlık indirme/yükleme hızları ile ping gecikmesi.
* **Modern Fluent & Glassmorphism Arayüz:** .NET 8 ve WebView2 üzerine kurulu akıcı, koyu temalı, modern neon ızgara efektli gösterge paneli.
* **Minimal HUD & Pop-out Desteği:** Ekranınızda yer kaplamayan dikey mini panel modu veya ikincil monitörler için bağımsız, çerçevesiz Pop-out widget penceresi.
* **Gelişmiş Sensör Kataloğu:** Sistemdeki tüm sensör havuzunu keşfedip kart slotlarına istediğiniz metriği tek tıkla sabitleme imkanı.
* **Sistem Tepsisi (Tray) & Akıllı Bellek Yönetimi:** Görev çubuğuna ve sistem tepsisine küçülebilme, sağ tık menüsünden tek tıkla Standby Bellek temizleme.

> ℹ️ **Not:** Uygulama arayüzü şu an Türkçe olarak sunulmaktadır. Çok yakında gelecek güncellemelerde **tam İngilizce dil desteği** (English localization) eklenecektir.

### 🇬🇧 English Description

**Meet CorePulse v1.0.0!**  
CorePulse is a modern, ultra-lightweight, and high-performance hardware monitoring center built as an open-source alternative to proprietary, bloated manufacturer utilities like MSI Center, ASUS Armoury Crate, and NZXT CAM.

#### ✨ Key Features:
* **Universal Hardware Discovery (Ring 0):** Automatically detects Intel, AMD, NVIDIA, ASUS, MSI, Gigabyte, and other hardware components without brand lock-in.
* **Real-Time Telemetry:** CPU & GPU clocks, voltages, hotspot and memory junction temperatures, real-time power draw (Watts), fan speeds (RPM), AIO pump telemetry, and SSD/NVMe drive health.
* **Precision Low-Level Tracking:** Native Win32 APIs for microsecond CPU load calculations, detailed physical memory metrics, real-time network throughput (Ethernet/Wi-Fi), and DNS ping latency.
* **Modern Fluent Glassmorphism UI:** Built with .NET 8 and WebView2, featuring sleek dark mode, glowing neon accents, and responsive layout.
* **Minimal HUD & Pop-out Widget:** Space-saving vertical HUD mode or standalone borderless pop-out mini windows for secondary displays or gaming.
* **Sensor Catalog & Custom Slot Pinning:** Browse every discovered hardware sensor and assign customized telemetry metrics to dashboard cards with a single click.
* **System Tray & Standby Memory Cleaner:** Runs quietly in the background tray with one-click Windows standby memory cleanup from the tray context menu.

> ℹ️ **Note:** The application UI is currently localized in Turkish. **Full English language support will be added very soon in an upcoming release!**
